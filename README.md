# 🎵 Music Streaming Analytics – Power BI Dashboard

## 📌 Project Overview
This project focuses on analyzing music streaming data using Power BI. It provides insights into streaming trends, popular songs, artists, albums, and listener behavior through interactive dashboards and visualizations.

## 🎯 Project Objectives
- Analyze music streaming trends.
- Identify the most popular songs and artists.
- Track total streams and listener engagement.
- Understand music popularity across different categories.
- Present insights through interactive dashboards.

## 🛠️ Technologies Used
- **Power BI** – Dashboard creation and data visualization.
- **Power Query** – Data cleaning and transformation.
- **DAX** – Creating measures and calculated columns.
- **Excel** – Data preparation and analysis.

## 📊 Key Features
- Total streaming statistics.
- Top-performing songs and artists.
- Music popularity analysis.
- Interactive filters and slicers.
- KPI cards and charts for better insights.

## ⚙️ Project Workflow
1. **Data Collection:** Imported music streaming dataset.
2. **Data Cleaning:** Cleaned and transformed data using Power Query.
3. **Data Analysis:** Created measures and calculations using DAX.
4. **Dashboard Development:** Designed interactive dashboards to visualize insights.
